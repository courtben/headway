# Headway

A small goal tracker: set a bigger goal, see your pace, and work ahead.

- **Total** goals (e.g. run 100 km in 100 days) with a pace line, weekly and monthly breakdowns.
- **Progression** goals (e.g. long run 5 → 21 km, push-ups Mon/Wed/Fri +5 a week).
- **Milestone** goals (a checklist with due dates).

Open the site on your phone and choose *Add to Home Screen* to install it. It works offline.
Everything is saved in your browser on that device only; use **Settings → Export backup** to keep a copy.
